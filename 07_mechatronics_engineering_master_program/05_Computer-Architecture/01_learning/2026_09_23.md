### Notes Section (Main Notes)

#### Memory Elements

#### Cross-Coupled Inverters: Bistable Circuit

Two cross-coupled NOT gates form a positive-feedback loop. Each inverter drives the input of the other, producing two stable states:

| State | $Q$ | $\overline{Q}$ |
|---|---:|---:|
| 1 | 1 | 0 |
| 2 | 0 | 1 |

The circuit stores **one bit**. Feedback preserves the current state after the forcing signal is removed. The complementary outputs should satisfy:

$$Q = \overline{\overline{Q}}$$

A bistable circuit has two stable operating points. It changes state only when an external signal forces one of its nodes.

#### NOR-Type SR Latch

Two cross-coupled NOR gates form an active-high SR latch:

```text
                 ┌─────────┐
        S ──────▶│   NOR   │────── Q
                 │         │        │
            Q̅ ──┤         │        │
                 └─────────┘        │
                                      ▼
                 ┌─────────┐        │
        R ──────▶│   NOR   │────── Q̅
                 │         │        │
             Q ──┤         │        │
                 └─────────┘
```

- `S = 1`: Set, $Q = 1$.
- `R = 1`: Reset, $Q = 0$.
- `S = R = 0`: Hold.
- `S = R = 1`: Invalid.

#### NAND-Type SR Latch

Two cross-coupled NAND gates form an active-low SR latch:

```text
                 ┌─────────┐
       S̅ ──────▶│  NAND   │────── Q
                 │         │        │
            Q̅ ──┤         │        │
                 └─────────┘        │
                                      ▼
                 ┌─────────┐        │
       R̅ ──────▶│  NAND   │────── Q̅
                 │         │        │
             Q ──┤         │        │
                 └─────────┘
```

- $\overline{S} = 0$: Set, $Q = 1$.
- $\overline{R} = 0$: Reset, $Q = 0$.
- $\overline{S} = \overline{R} = 1$: Hold.
- $\overline{S} = \overline{R} = 0$: Invalid.


- **S — Set:** forces $Q = 1$.
- **R — Reset:** forces $Q = 0$.
- **Hold:** preserves the previous state.

A NOR-gate SR latch uses active-high inputs:

| S | R | Q(next) | Operation |
|---:|---:|---:|---|
| 0 | 0 | Q | Hold |
| 1 | 0 | 1 | Set |
| 0 | 1 | 0 | Reset |
| 1 | 1 | Invalid | Forbidden state |

When $S = 1$ and $R = 1$, both NOR outputs become `0`, so $Q$ and $\overline{Q}$ are no longer complementary. Returning both inputs to `0` can produce an unpredictable final state because of propagation-delay differences.

A NAND-gate SR latch uses active-low inputs, $\overline{S}$ and $\overline{R}$:

| $\overline{S}$ | $\overline{R}$ | Operation |
|---:|---:|---|
| 1 | 1 | Hold |
| 0 | 1 | Set |
| 1 | 0 | Reset |
| 0 | 0 | Invalid |

#### Gate SR Latch

A **Gate SR latch** is an SR latch controlled by an enable input, $E$. It changes state only when enabled. When $E = 0$, the latch holds its previous state; when $E = 1$, the S and R inputs control the latch.

For an active-high, NOR-based Gate SR latch:

| E | S | R | Q(next) | Operation |
|---:|---:|---:|---:|---|
| 0 | X | X | Q | Hold; latch disabled |
| 1 | 0 | 0 | Q | Hold |
| 1 | 1 | 0 | 1 | Set |
| 1 | 0 | 1 | 0 | Reset |
| 1 | 1 | 1 | Invalid | Forbidden state |

`X` means “don't care”: S and R do not affect the output while the latch is disabled.

```text
             S ──────┐
                      ▼
                    ┌─────┐
             E ────▶│ AND │──── S' ──┐
                    └─────┘          ▼
                                  ┌─────┐
                                  │ NOR │──── Q
                                  └──┬──┘
                                     │
                                  ┌──▼──┐
                                  │ NOR │──── Q̅
                                  └─────┘
             R ──────┐
                      ▼
             E ────▶┌─────┐
                    │ AND │──── R' ──┘
                    └─────┘
```

#### D Latch

A **D latch** is a gated latch with one data input, $D$. It uses an inverter to generate complementary inputs:

$$S = D \cdot E$$

$$R = \overline{D} \cdot E$$

This prevents the invalid SR condition $S = R = 1$. When enabled, the output follows the input; when disabled, the output remains stored.

| E | D | Q(next) | Operation |
|---:|---:|---:|---|
| 0 | X | Q | Hold |
| 1 | 0 | 0 | Reset / store 0 |
| 1 | 1 | 1 | Set / store 1 |

```text
                         ┌─────────┐
             D ─────────▶│         │
                         │ D Latch │──── Q
             E ─────────▶│         │
                         └─────────┘
                                      └── Q̅
```

The D latch is **level-sensitive**:

- $E = 1$: transparent; $Q$ follows $D$.
- $E = 0$: opaque; $Q$ holds its previous value.

#### D Flip-Flop

A **D flip-flop** is an edge-triggered memory element that samples the input $D$ at a specific clock edge and stores that value at the output $Q$. Unlike a D latch, it does not remain transparent throughout a clock level.

| Clock event | D | Q(next) | Operation |
|---|---:|---:|---|
| No active edge | X | Q | Hold |
| Rising edge $\uparrow$ | 0 | 0 | Store 0 |
| Rising edge $\uparrow$ | 1 | 1 | Store 1 |

For a falling-edge-triggered flip-flop, replace the rising edge $\uparrow$ with the falling edge $\downarrow$.

##### Master-Slave Architecture

A master-slave D flip-flop uses two D latches connected in series and controlled by opposite clock phases:

```text
             ┌────────────┐       ┌────────────┐
      D ────▶│ Master     │──────▶│ Slave      │──── Q
             │ D latch    │       │ D latch    │
       CLK ─▶│ CLK̅       │  ────▶│ CLK        │
             └────────────┘       └────────────┘
```

The master captures the input during one clock phase. The slave updates the output during the opposite phase. This prevents the input from passing directly to the output during the entire clock level.

##### Operating Sequence

For a positive-edge-triggered master-slave D flip-flop:

1. **CLK = 0:** The master is transparent and samples $D$; the slave holds $Q$.
2. **Rising edge:** The master closes; the slave opens.
3. **CLK = 1:** The slave transfers the master's stored value to $Q$.
4. **Falling edge:** The slave closes; the master becomes transparent again.

Therefore:

$$Q_{next} = D \quad \text{at the active clock edge}$$

##### D Latch vs D Flip-Flop

| D latch | D flip-flop |
|---|---|
| Level-sensitive | Edge-triggered |
| Uses enable or clock level | Uses clock edge |
| $Q$ follows $D$ while enabled | $Q$ samples $D$ once per edge |
| Can be transparent during part of a clock cycle | Prevents continuous data transparency |

### Summary Section (Summary of Notes)

Cross-coupled inverters form a bistable circuit with two stable states and can store one bit through positive feedback. An SR latch adds Set and Reset control inputs. A Gate SR latch adds an enable input, allowing the latch to hold or respond to S and R. A D latch combines S and R into one data input, preventing the invalid SR condition. When enabled, a D latch follows $D$; when disabled, it holds its previous state. A D flip-flop samples $D$ only at the active clock edge, using master-slave latches to provide edge-triggered operation.
