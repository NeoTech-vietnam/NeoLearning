# Introductory DSP Study Pack

This pack links the local lecture deck to exact reading locations in Richard G. Lyons's *Understanding Digital Signal Processing*, Third Edition. Page references distinguish printed book pages from 1-based PDF page ordinals.

## Read and practice

- [Book reading map](book_reading_map.md) — section-level reading assignments with both page systems.
- [Lecture examples](lecture_examples.md) — full-deck text-scan locator map for worked examples in 00_Intro.pdf, plus the existing DAC exercise.
- [Core concepts](core_concepts.md) — Cornell-style explanations connecting sequences, systems, transforms, filters, and mechatronic use.
- [Practice exercises](practice_exercises.md) — the six existing DAC/reconstruction questions and ten additional original exercises.
- [Answer key](practice_answers.md) — worked results and checks, separated from the exercises.

## What the lecture contains

The text scan found worked examples across systems, difference equations, z-transforms, DFT/FFT, filter design, and finite-precision effects. It found no slide labeled Exercise, Question, Homework, or Assignment. Four incidental occurrences of the word “problem” do not form a problem set, so the practice file identifies the existing DAC DOCX and labels new questions as original.
