### Notes Section (Main Notes)

#### Development Process

- This chapter provides a short overview of how to use RTA-OS in your applications.
- The process involves the following steps:
  - Configure the features of the OS you want to use
  - Generate a customized RTA-OS kernel library
  - Write application code that uses the OS
  - Compile your application code and linking with the RTA-OS library
  - Run your application on your target 

- As this documentation is targeting for general knowledge about the RTA-OS. There would be some specific development tools. Hence, the following sections will by-bass the details of the development tools and focus on the general process of using RTA-OS in your applications.
