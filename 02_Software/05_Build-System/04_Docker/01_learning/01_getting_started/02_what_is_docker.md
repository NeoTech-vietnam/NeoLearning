### Notes Section (Main Notes)

Docker is a container technology: A tool for creating and managing containers.

- **Container**: A standardized unit of software, which basically means a package of code and dependencies to run that code (e.g. NodeJS code + NodeJS runtime)

The same container always yields the exact same application and execution behavior! No matter where or by whom it might be executed.

Support for Containers is built into modern operating systems!

**Docker simplifies** the creation and management of such containers.
