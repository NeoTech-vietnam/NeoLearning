### Notes Section (Main Notes)

#### How is the `main.go` file organized?
- There are three main sections in the `main.go` file:

##### 1. Package Declaration: 
- This is where you declare the package name at the top of the file. For example, `package main`.

##### 2. Import Statements: 
- This section is where you import any necessary packages that your program will use. For example, `import "fmt"`.

##### 3. Main Function
- This is the entry point of the program where the execution starts. It is defined as `func main() { ... }`.
