#### How do we run the code in our project?
- First, you should check all the go commands by running:
```go
go help
```
- To run the code, you can use the command:
```go
go run main.go
```
- Some common `go` commands include:
  - `go build`: Compiles the packages and dependencies.
  - `go test`: Runs tests.
  - `go fmt`: Formats the source code.
  - `go get`: Downloads and installs packages.
  - `go run`: Compiles and runs the specified Go program.
  - `go install`: Compiles and installs the packages.
  - `go clean`: Removes object files and cached files.
