### Notes Section (Main Notes)

#### Structs in Go
- A struct is a composite data type that groups together variables under a single name.
- Each variable in a struct is called a field.
- Structs are used to create complex data types that represent real-world entities.

#### Defining a Struct
- You can define a struct using the `type` keyword followed by the name of the struct and the fields it contains.
```go
type Person struct {
    Name string
    Age  int
}
```
