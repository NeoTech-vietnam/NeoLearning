### Notes Section (Main Notes)

```go
func newDeck() deck {
	cards := deck{}

	cardSuits := []string{"Spades", "Diamonds", "Hearts", "Clubs"}
	cardValues := []string{"Ace", "Two", "Three", "Four"}

	for _, suit := range cardSuits {
		for _, value := range cardValues {
			cards = append(cards, value+" of "+suit)
		}
	}
	return cards
}
```
- With this `func newDeck()`:
  - `deck` after `newDeck()` is a return data when we call the function.
  - We create an empty `deck` called `cards`.
  - We create two slices: `cardSuits` and `cardValues` to hold the suits and values of the cards.
  - We use nested loops to iterate over each suit and value, appending a string representation of each card to the `cards` slice.
  - Finally, we return the `cards` slice, which now contains a full deck of cards.
- The output of the program will be a list of all the cards in the deck, such as "Ace of Spades", "Two of Spades", etc., for each combination of suit and value.
```cmd
0 Ace of Spades
1 Two of Spades
2 Three of Spades
3 Four of Spades
...
```
- The indexes (0, 1, 2, etc.) are automatically generated by the `print()` method when it iterates over the `cards` slice and prints each card with its corresponding index.
