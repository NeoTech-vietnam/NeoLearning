- Direct element access
- Provides access to the underlying raw array
- Use instead of raw arrays when possible
- All iterators available and do not invalidate

### Summary Section (Summary of Notes)

- `std::array` is a fixed-size container introduced in C++11.
- It provides direct element access and access to the underlying raw array.
- Use `std::array` instead of raw arrays when possible.
- All iterators are available and do not invalidate.
- For more information, visit the [STL cpp reference website](https://en.cppreference.com).
