#### Testing for Equality
- **The == and != operators**
  - Compares the values of 2 expressions
  - Evaluates to a Boolean (True or False, 1 or 0)
  - Commonly used in control flow statements
```cpp
expr1 == expr2
expr1 != expr2
100 == 200
num1 != num2
```
