# Cornell evidence notes

1. Read the assignment and existing notes. Consolidate a finding into one visible narrative and link it from the engineering records.
2. Collect sources with titles, retrieval dates, locators, and local file or record fingerprints. Mark material claims as observed, source-reported, expected, or inferred.
3. Select the Cornell evidence recipe when applicable. Record concrete inputs, an expected result, a demonstration, failure cases, and separate practice and answer files. Preserve user-written solutions.
4. A root-cause note includes reproduction, hypotheses, eliminating evidence, a confirmed or unresolved conclusion, repair, and regression results.
5. Validate format, citations, links, artifacts, and local source freshness. Obtain the required independent review for correctness. Only actual execution evidence supports observed results.

Completion requires a current validated note, engineering links, substantive sources, a concrete demonstration, and practical exercises. The exact quote comes from the installed Cornell template. The managed knowledge record stores references and provenance; the visible note owns the narrative.
