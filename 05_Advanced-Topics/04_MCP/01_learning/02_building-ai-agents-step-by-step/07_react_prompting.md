### Notes Section (Main Notes)

#### ReAct Prompting

Use the LLM to simulate thoughts.

`Thinking` instructions in the system prompt to encourage the LLM to reason step-by-step before taking an action.

LLM executes the function and observes the result.

The observation is appended to the messages history and the loop continues.

---

### Summary Section (Summary of Notes)

ReAct Prompting allows the LLM to simulate thoughts, reason step-by-step, execute functions, and observe results, creating a loop of continuous reasoning and action.
