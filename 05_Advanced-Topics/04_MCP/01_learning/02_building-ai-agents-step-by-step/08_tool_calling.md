### Notes Section (Main Notes)

#### Tool Calling

Augmenting LLMs' capabilities.

The LLM can choose to use a tool before responding to your query.

Some models `think` before using tools. Others are more prone to using tools.

The tools are just functions with descriptions of what they do.

---

### Summary Section (Summary of Notes)

Tool Calling allows LLMs to augment their capabilities by choosing to use tools before responding to queries. Some models think before using tools, while others are more prone to using them. Tools are essentially functions with descriptions of their functionality.
