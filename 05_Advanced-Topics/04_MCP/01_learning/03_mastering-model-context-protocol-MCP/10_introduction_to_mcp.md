### Notes Section (Main Notes)

#### Agents Need Tools

LLMs are stateless and limited to their training data

Calling APIs (e.g., fetching stock prices, weather, documents)

Running code (e.g., calculators, data processors)

Reading from and writing to databases

Interacting with the filesystem or external services

#### The Problem

Most frameworks today hardcode these tools into the agent's environment.

- Code duplication across projects.
- Difficult maintenance and scalability.
- No standard way to share tools across agents or teams.

#### The Solution: Model Context Protocol (MCP)

A light-weight protocol that connects agents (clients) to tools (servers).
